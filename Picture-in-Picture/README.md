# Universal Auto PiP

A lightweight extension that enables and automates native Picture-in-Picture mode for web media.

## 🚀 Overview

**Universal Auto PiP** keeps your media on top while you work. It enables the native browser Picture-in-Picture (PiP) toggle for video players that otherwise restrict, hide, or disable the standard PiP button.

## ✨ Key Features

- **Universal Detection**: Automatically identifies media elements on any webpage.
- **Native Integration**: Leverages the browser's built-in PiP API for maximum performance and stability.
- **Toggle Control**: Easily enter or exit PiP mode with a single click on the extension icon.
- **Auto-Detection**: Version 2.0 includes intelligent detection to open media in PiP automatically when you switch tabs (context-dependent).
- **Lightweight**: Minimal background footprint with a service worker-based architecture.

## 🛠️ Installation

1. Download the extension source code.
2. Go to `chrome://extensions/` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the extension directory.

## 📖 How to Use

1. Navigate to a page with a video player (YouTube, Twitch, etc.).
2. Click the extension icon in your toolbar.
3. The video will pop out into the native PiP window, allowing you to resize and move it anywhere on your screen.
4. Click again to return the video to the original tab.
