# Privacy Policies

This repository contains the privacy policies for various applications and browser extensions.

## Available Policies

| Application / Extension | Description |
| :--- | :--- |
| [Allow Copy and Paste](copy-paste.md) | Restores standard browser interactions like copying and pasting. |
| [Bookmarks](bookmarks.md) | Provides a high-performance navigation interface for browser bookmarks. |
| [Call Guard Shield](call-guard-shield.md) | Android application for call filtering, spam detection, and local database management. |
| [Cookie-Manager](cookie-manager.md) | Helps maintain privacy by automating cookie cleanup. |
| [Element-Hider](element-hider.md) | Allows customizing the web experience by hiding unwanted elements. |
| [NWS Alerts](nws-alerts.md) | Provides real-time weather notifications. |
| [PDF-Tools](pdf-tools.md) | Privacy-first browser extension for managing PDF files. |
| [Picture-in-Picture](pip.md) | Utility extension for video players to enable native browser PiP mode. |
| [XtendedMenu](xtended-menu.md) | Windows utility designed to enhance workflow and productivity. |

## Contact

If you have any questions regarding these privacy policies, please open an issue in this repository.
