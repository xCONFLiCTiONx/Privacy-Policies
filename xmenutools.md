# xMenuTools Privacy Policy

**Effective Date:** August 5, 2026

xMenuTools is an archived utility suite for extending the Windows context menu.

## 1. System Modifications
The tools in this suite modify local system settings and the Windows Registry to add context menu entries as requested by the user.

## 2. Privacy
xMenuTools does not collect, store, or transmit any user data. All operations are performed locally on the user's machine. No background telemetry or analytics are included.
