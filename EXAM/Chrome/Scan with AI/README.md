Gmail Security Analyzer



INSTALL:



1\. Open Chrome:

chrome://extensions



2\. Enable:

Developer mode



3\. Click:

Load unpacked



4\. Select this extension folder.





SETUP:



1\. Open extension options.



2\. Enter your Gemini API key.



3\. Save.





TEST:



1\. Open Gmail.



2\. Open an email.



3\. Look for:



🛡 Scan Email



4\. Click it.



5\. Wait for Gemini analysis.





FEATURES:



\- Gmail email scanning

\- Gemini AI analysis

\- Phishing detection

\- Suspicious language detection

\- Sender analysis

\- URL checks

\- Attachment checks





CURRENT LIMITATIONS:



\- Gmail API raw headers are not enabled yet.

\- Full SPF/DKIM/DMARC extraction requires Gmail API OAuth.

\- Current version analyzes visible email content.
