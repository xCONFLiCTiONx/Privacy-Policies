# Gmail Security Analyzer Privacy Policy

**Effective Date:** August 5, 2026

Gmail Security Analyzer is a Chrome extension that leverages AI to identify security threats and phishing attempts in your emails.

## 1. Data Processing
- **Email Content:** When you analyze an email, the relevant text content is sent to Google's Gemini API to assess risks and provide security insights.
- **Local Analysis:** Some basic risk scoring is performed locally before being sent for AI analysis.

## 2. AI Integration
This extension requires a user-provided Google Gemini API key. All AI-powered analysis is subject to Google's privacy standards for the Gemini API. We do not store or see your API key or the content of your emails.

## 3. Security Focus
The primary purpose of data processing is to identify high-pressure keywords, suspicious call-to-action phrases, and other indicators of phishing. Results are displayed only to you within the Gmail interface.
