# AutoLock Privacy Policy

**Effective Date:** August 5, 2026

AutoLock is a utility to set time limits for computer user sessions, designed for environments like libraries and schools.

## 1. Functionality
The application monitors session duration locally on the machine where it is installed to enforce user-defined time limits.

## 2. Data Privacy
AutoLock does not collect, transmit, or share any personal information. All session management and timing data stay strictly local to the device. No internet connection is required for its core functionality.
