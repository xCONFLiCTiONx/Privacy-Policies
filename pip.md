# Universal Auto PiP Privacy Policy

**Effective Date:** August 5, 2026

Universal Auto PiP is a utility extension that enables and automates Picture-in-Picture mode for web media.

## 1. Functionality
The extension interacts with media elements (video and audio) on webpages to enable the native browser Picture-in-Picture mode. It can automatically detect active media to streamline the PiP experience. 

The extension does not monitor the content of the media you watch or track your viewing habits.

## 2. Permissions
- **Active Tab:** Used to interact with media on the page you are currently viewing.
- **Scripting:** Used to inject the necessary logic to trigger the PiP functionality.

## 3. Privacy
All processing occurs locally in your browser. No data regarding your browsing activity, visited URLs, or media consumption is collected or transmitted.
