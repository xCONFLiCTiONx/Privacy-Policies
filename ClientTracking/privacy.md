# ClientTracking Privacy Policy

**Effective Date:** August 21, 2026

ClientTracking is a client management and barcode tracking system designed for specific business environments.

## 1. Scope
This policy covers the ClientTracking desktop application and its associated database interactions.

## 2. Data Collection and Storage
ClientTracking is designed to store data in a user-managed Microsoft SQL Server instance. The types of data stored include:
- Client identification (Barcode IDs)
- Personal information (Names, history records)
- Photographs (if configured)
- Locker assignment data

## 3. Data Transmission
All data remains within the local network or server environment configured by the developer/administrator. The application does not automatically transmit client data to external servers or third-party services.

## 4. Developer Responsibility
Organizations implementing ClientTracking are responsible for ensuring their SQL Server environment is secure and that their data collection practices comply with relevant local and international privacy regulations.
