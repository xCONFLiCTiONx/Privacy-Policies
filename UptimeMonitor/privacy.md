# UptimeMonitor Privacy Policy

**Effective Date:** August 21, 2026

UptimeMonitor is a system utility for tracking and reporting application uptime.

## 1. Scope
This policy applies to the UptimeMonitor console application and its reporting functions.

## 2. Data Collection
UptimeMonitor collects technical data related to system availability and uptime. It does not collect personal user information, browsing history, or private files.

## 3. Data Transmission
Status reports are uploaded to an FTP/SFTP server specified by the user in the application settings. Configuration settings (such as "Quiet Time") may also be synced to the remote server to maintain consistency.

## 4. Security
Users are responsible for the security of their remote server credentials. We recommend using SFTP for secure data transmission.
